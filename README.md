# Tunnela VIP

Tunnela is the renamed FoxyVPN Android client with a premium Liquid Glass-inspired UI, Windscribe-inspired information hierarchy, smooth connection animations, and the supplied Tunnela shield icon.

## Build

Use GitHub Actions -> Build APK. The workflow installs Android platform 35, build tools 35.0.0, and NDK 26.1.10909125, then uploads `Tunnela-debug-APK`.
